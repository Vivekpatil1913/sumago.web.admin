# Sumago Website — Documentation

This `docs/` repository is the **single source of truth** for the Sumago Infotech website rebuild. Every design, content, and engineering decision defers to these documents. When code and docs disagree, fix the mismatch — don't let it linger.

## How to use these docs
- **Building a feature?** Start with [01 — Project Vision](01-project-vision.md) and [04 — Information Architecture](04-information-architecture.md).
- **Designing UI?** [02 — Brand Guidelines](02-brand-guidelines.md) + [03 — Design System](03-design-system.md) + [06 — Motion Principles](06-motion-principles.md).
- **Writing copy?** [08 — Content Strategy](08-content-strategy.md).
- **Writing code?** [10 — Technical Architecture](10-technical-architecture.md) + [11 — Coding Standards](11-coding-standards.md).
- **Shipping?** [12 — SEO](12-seo.md), [13 — Accessibility](13-accessibility.md), [14 — Testing](14-testing.md), [15 — Deployment](15-deployment.md).
